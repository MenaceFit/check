Comment utiliser
1

Glisser le bouton dans vos favoris

Glissez le bouton ⚡ Quick Checkout ci-dessus directement dans votre barre de favoris du navigateur. Si la barre n'est pas visible : Ctrl+Shift+B (Windows/Linux) ou Cmd+Shift+B (Mac).

2

Activer sur autocop.app

Allez sur autocop.app et cliquez le bookmarklet ⚡ dans vos favoris. Des boutons CHECKOUT apparaissent sur chaque article Vinted. Cliquez le bouton ⚡ flottant (bas-droite) pour configurer le marché et activer l'autobuy.

3

Cliquer CHECKOUT sur un article

Cliquez le bouton ⚡ CHECKOUT sur un article — Vinted s'ouvre dans un nouvel onglet. Passez sur cet onglet, puis re-cliquez le bookmarklet ⚡ pour lancer l'autobuy automatiquement.

Fonctionnalités
⚡

Boutons CHECKOUT

Injection automatique sur tous les liens Vinted détectés dans le feed autocop.app.

🤖

Autobuy

Clique Acheter → Livraison → Payer automatiquement. Overlay de progression en temps réel.

✅

Dispo en temps réel

Vérifie la disponibilité via l'API Vinted (token requis). Articles vendus affichés en gris.

🔒

100% local

Aucune donnée envoyée à l'extérieur. Paramètres stockés uniquement dans votre navigateur.

Token Bearer (optionnel)

Le token Bearer permet la vérification de disponibilité en temps réel. Pour l'obtenir :

  • 1. Connectez-vous sur Vinted dans votre navigateur
  • 2. Ouvrez les DevTools (F12) → Onglet Réseau
  • 3. Filtrez sur /api/v2/ → Cherchez le header Authorization: Bearer ...
  • 4. Copiez le token et collez-le dans les paramètres ⚡

Compatibilité navigateurs

Ce bookmarklet fonctionne sur tout navigateur moderne. Pour DuckDuckGo Desktop : activez la barre de favoris dans les paramètres si elle n'est pas visible. Le bookmarklet s'exécute sur la page courante sans aucune installation supplémentaire.
